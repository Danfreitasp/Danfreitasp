## Projetos principais

### [CRM Consignado](https://github.com/Danfreitasp/crm-consignado)

Sistema de gestão para centralizar clientes, propostas e rotinas de atendimento.

- Funil Kanban configurável
- Gestão de clientes e propostas
- Portabilidade e refinanciamento vinculados
- Agenda de retornos e acompanhamento diário
- Dashboard de produção e comissões
- Simulador INSS e gerador de mensagens
- Importação e exportação de planilhas
- Histórico, notificações e backups locais

O projeto utiliza **Python, Flask, SQLite, Jinja, HTML, CSS e JavaScript**. O repositório público funciona como vitrine; o código operacional e os dados permanecem privados.

### [Central WhatsApp Web](https://github.com/Danfreitasp/central-whatsapp-web)
- [Versão 0.10.31 Win x64](https://github.com/Danfreitasp/central-whatsapp-web-updates/releases/download/v0.10.31/Central-WhatsApp-Web-Setup-0.10.31.exe)

Aplicativo para centralizar múltiplas sessões do WhatsApp Web e organizar operações de atendimento e disparos.

- Múltiplos números e sessões independentes
- Importação de listas e planilhas
- Disparos individuais e distribuídos entre números
- Busca global por contatos, telefones e mensagens
- Histórico, notificações e atualizações automáticas

O repositório público disponibiliza o código-fonte. Os instaladores e metadados de atualização ficam no [repositório de releases](https://github.com/Danfreitasp/central-whatsapp-web-updates).
